# 自动点击器 (AutoClicker)

一个基于 Python + tkinter 的图形化自动点击工具，支持多位置、多轮次点击，完全可自定义。

## ✨ 功能特性

- 🖱️ **多位置点击** — 支持多个点击位置，按顺序依次执行
- ⏱️ **独立间隔** — 每个位置可设置独立的点击次数和点击间隔
- 🔄 **多轮循环** — 可设置执行轮数，0 为无限循环
- ⏸️ **组后等待** — 每个位置/每轮结束后可设置等待时间
- 🎯 **3秒倒计时取坐标** — 点击按钮后有时间把鼠标移到目标位置
- 🛑 **紧急停止** — 鼠标移到屏幕左上角立即停止
- 🖼️ **窗口可缩放** — 自由调整窗口大小，列表自适应
- 📦 **一键打包** — 支持打包成独立 exe 和安装包，可移植到其他电脑

## 🚀 快速开始

### 方式一：直接运行源码

需要 Python 3.7+

```bash
# 安装依赖
pip install pyautogui

# 运行
python auto_clicker.py
```

或者直接双击 `启动自动点击器.bat`。

### 方式二：打包成独立 exe

```bash
# 双击运行
build_exe.bat
```

打包完成后在 `dist/AutoClicker.exe`，可以直接拷到其他 Windows 电脑上运行，不需要装 Python。

### 方式三：制作安装包

1. 先打包 exe
2. 安装 [Inno Setup](https://jrsoftware.org/isdl.php)
3. 双击运行 `build_installer.bat`

生成的安装包在 `Output/AutoClicker-Setup.exe`，支持安装向导、开始菜单、桌面快捷方式、卸载程序。

## 📖 使用说明

### 添加点击位置
1. 点击"添加位置"按钮
2. 双击单元格编辑数值，或选中行后点"获取当前位置坐标"
3. 每个位置可设置：X坐标、Y坐标、点击次数、点击间隔(秒)

### 全局设置
- **组后等待(秒)** — 点完一个位置后，等多久再开始下一个位置
- **执行轮数** — 总共循环执行多少轮，填 0 为无限循环
- **每轮间隔(秒)** — 每执行完一轮后，等多久再开始下一轮

### 开始点击
1. 设置好位置和参数
2. 点击"开始点击"
3. 随时可点"停止"按钮
4. 紧急情况下把鼠标移到屏幕左上角也会立即停止

## ⚠️ 注意事项

- 本工具仅供学习和自动化测试使用
- 请勿用于游戏作弊或其他违规用途
- 使用时请注意不要误操作重要窗口
- 间隔时间设为 0 可能导致系统卡顿，请谨慎使用
